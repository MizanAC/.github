# Security

To report a security problem in mizan.ac, the Mizan API, the server module or the detection service, email
contact@mizan.ac with a subject that starts with "Security:". Please don't open a public issue.

What is covered, what to include and what we do with a report are in the full policy at
[mizan.ac/security](https://mizan.ac/security). Cheats, ways past detection and ban evasion are not vulnerabilities
under it.
